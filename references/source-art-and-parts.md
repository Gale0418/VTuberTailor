# 原圖、拆件與補遮擋

使用者提供的原圖或明確指定的參考圖是角色外觀的權威。記錄本次來源與範圍，保持畫布座標和臉部錨點一致；不能因為拆層方便而改變角色比例、眼睛大小／位置、瞳孔、眉鼻嘴、臉型、原有筆觸或配色。

## 拆件原則

- 先從原圖直接分離原有像素。前髮、後髮、臉、耳、眼、身體、手臂、衣裙、襪與配件等均按實際遮擋關係盤點；不要只列會動的顯眼部件而漏掉皮膚、衣裙襪或前後髮。
- 每個部件以真實 alpha 透明保存，避免白底、棋盤格或低透明底色烘焙進圖。用淺底與深底都檢視；白／亮膚色區不得靠色差挖空，避免把高光、皮膚或抗鋸齒一起刪掉。
- 補被遮住的區域時，延續原畫線條、材質、陰影及遮擋邊界。虹膜內烘焙髮絲、睫毛和髮片殘留、耳緣 matte、耳根、裙襪間皮膚缺口都要放大檢查；缺少足夠上下文時先判定素材是否能支持目標，不能憑空宣稱修復完成。
- 任何程式化圖像編修（包括 Python）須有使用者本次明確授權，授權限於該任務範圍。過往曾允許不代表此後永久允許。

## 視覺檢查方式

對每一個拆件／補件輸出：檢查真透明；分別合成白色及深色背景；以 200% 或更高比例查看邊緣、細節與接縫；再將部件半透明疊回來源圖，檢查對齊、像素來源及臉部錨點。這些是每件素材都要完成的檢查，不可只抽看代表件。

需要新增／註冊素材時，依 `register --help` 取得支援參數與格式。每件 asset 使用各自正確的 immutable reference；sourceRect 必須代表該素材在來源畫布的原始位置與範圍。不要用不同素材共用錯誤 reference，也不要手動改 canonical JSON 繞過 API 或 revision guard。
